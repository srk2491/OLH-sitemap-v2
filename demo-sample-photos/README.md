# Demo sample photos

These are generic stock photos, NOT actual RGHCL sites. Keep the DEMO ONLY caption when presenting them. The bundled demo attaches the exterior/balcony photos to Horamavu Agara (1-7) and the interior photo to Bidarahalli (1-6) through data/media.json. Exactly these two site galleries contain samples. Select the same sites in the official workspace to edit them. They can be replaced or removed later.
