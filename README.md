# OLH sitemap v2 demo

Separate public demonstration of OLH explorer v1.5.1. The original OLH-sitemap repository is unchanged.

Includes accessibility controls, independent 1/2 BHK numbering, grouped locations and signed quota display.

This repository contains public deployment files only. Photos bundled with this release are labelled demo samples. Availability is a report snapshot, not a live feed; confirm figures with RGHCL. Local-only report updates and photos are not included.

To enable hosting: Settings → Pages → Deploy from a branch → main → / (root) → Save.
